# Project Limitations

## Current Limitations

1. This project is designed for educational use only.
2. The application runs locally and is not intended for public deployment.
3. Login credentials are demo credentials.
4. Password storage is not implemented as a production-grade system.
5. CSRF protection is not included.
6. Rate limiting is not implemented.
7. Automated tests cover only selected security controls.

## Future Improvements

1. Add secure password hashing.
2. Implement CSRF protection.
3. Add login rate limiting.
4. Improve authentication and session management.
5. Add more automated regression tests.
6. Improve test reporting and evidence collection.

## Safety

Use this project only on localhost or systems
for which written testing permission is available.
